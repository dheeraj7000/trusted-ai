**[Click: "Receipts" tab]**

> "Here's the proof receipt — a cryptographic certificate for this agent run. It contains:"

Point out on screen:
- **Provenance root** — hashes of all source data
- **Trace root** — hash of the full execution timeline
- **State root** — image digest, SBOM, policy version
- **Receipt root** — the master hash binding everything together

> "This isn't a log. It's independently verifiable evidence."

**[Click: "Verify Receipt" button]**

> "Anyone can verify this receipt. The verifier independently recomputes every hash and checks the signature. All green — VALID."

## 🏗️ TECHNICAL ARCHITECTURE (if asked)

```
React / Next.js Demo UI (CloudFront HTTPS)
   |
   v
FastAPI AgentProof Gateway (ECS Fargate) ---------> Demo Tool APIs
   |                                                 refund / data_send
   +--> Policy Engine (Python/YAML rules)
   |
   +--> OpenTelemetry SDK -> trace events
   |
   +--> Provenance Hasher -> SHA-256 Merkle root
   |
   +--> State Manifest -> image/SBOM/CBOM/policy digests
   |
   +--> Evidence Signer -> AWS KMS (ECDSA P-256)
   |
   +--> Proof Receipt (receipt.json)
   |
   v
   Independent Verifier (recomputes all hashes + checks signature)
```

### AWS Services Used
- **ECS Fargate** — Backend + Frontend containers
- **ECR** — Container image registry
- **KMS** — Asymmetric signing key (ECDSA P-256)
- **S3** — Evidence storage bucket
- **CloudFront** — HTTPS CDN with API routing
- **ALB** — Load balancer between services

### Key Design Decisions
- Policy engine is **outside** the model prompt — can't be bypassed by prompt injection
- Uses **SHA-256 Merkle trees** for provenance, trace, and state roots
- **Canonical JSON** serialization ensures deterministic hashing
- **AWS KMS** for signing — private key never leaves hardware
- **OpenTelemetry** standard for telemetry — not a proprietary format
- Local dev key fallback for development without AWS

## 🎯 TIPS FOR RECORDING

3. **Pause briefly** after each ALLOW/BLOCK animation so viewers can read

5. **End on the closing line** — "We let you verify it" is the hook
6. **Total time target: 4-5 minutes** (3 min demo + 1 min business + 10s close)
